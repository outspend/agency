# Ketamine Gary

An AGENCY comic cartridge. Four-panel deadpan parody of a polished
direct-to-consumer ketamine-therapy testimonial ad: an ordinary man's
mental-health success story quietly, inexplicably escalates into
proximity with presidential power. The testimonial copy stays sincere
and mundane throughout — the joke is carried entirely by the images.

## Files

- `prompt.txt` — the cartridge. Canonical, machine-readable prompt payload.
- `index.html` — human-facing landing page.

## Running the cartridge

Give this URL to an AI assistant with image generation:

```
https://raw.githubusercontent.com/outspend/agency/main/comics/ketamine-gary/prompt.txt
```

Attach one clear photo of a person to cast them as Gary; otherwise a
default Gary is used. See `prompt.txt` itself for the full rule.
