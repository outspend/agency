AGENCY

Generative comic cartridges

AGENCY publishes comics as cartridges: durable, plain-text instruction payloads that any AI assistant can fetch and run to regenerate the comic — optionally swapping in a supplied reference person for one of its roles.

No app, no account, no build step. Each cartridge is just a URL ending in prompt.txt.
